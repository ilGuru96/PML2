# Reclutamento

Questa cartella è la superficie isolata della schermata di reclutamento.

- `recruitment.css` contiene il layout del pannello nel box mappa e le sue protezioni dai layout generali.
- Il flusso di gioco resta nel core in `../../core/core.js`, nella sezione `RECRUITMENT SYSTEM`: viene mantenuto lì perché aggiorna direttamente squadra, ricompense e avanzamento della run.

Per modifiche estetiche alla schermata intervenire qui, senza cambiare le regole globali dei pannelli mappa.
